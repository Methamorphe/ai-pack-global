# UI Audit

Do not redesign immediately.

Evaluate:
- hierarchy
- layout/alignment
- spacing
- typography
- color
- components
- navigation
- density
- loading/empty/error states
- responsive behavior
- accessibility

Return:
- critical issues
- high-impact improvements
- consistency issues
- responsive issues
- accessibility issues
- polish
