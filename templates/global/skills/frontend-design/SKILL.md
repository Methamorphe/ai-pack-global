# Frontend Design

Before coding determine:
- product purpose
- target user
- primary action
- hierarchy
- existing design language
- responsive requirements

Avoid generic AI UI:
- default purple/blue gradients
- glassmorphism everywhere
- giant radii/cards
- decorative blobs
- excessive pills
- repetitive icon/title/text grids
- generic startup landing pages
- excessive shadows

Use deliberate typography, semantic color, alignment, spacing rhythm, appropriate density, and real interaction states.

Treat mobile intentionally.

Reuse existing tokens/components first.
