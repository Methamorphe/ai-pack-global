# Dependency Research

Determine exact dependency and installed version.

Prefer:
1. official docs
2. official repo
3. official release notes
4. maintainer docs

Never invent APIs.

Prefer version-specific documentation.

If local types/code conflict with docs, investigate and trust verifiable evidence.
