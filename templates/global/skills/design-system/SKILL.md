# Design System

Inspect/define:
- typography
- spacing
- radii
- borders
- shadows
- surfaces
- semantic colors
- iconography
- motion

Prefer semantic tokens.

Create reusable components only when visual/behavioral semantics genuinely repeat.

Define intentional:
- hover
- focus
- active
- selected
- disabled
- loading
- error
states.
