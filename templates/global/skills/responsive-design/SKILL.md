# Responsive Design

Responsive design is not shrinking desktop.

Adapt:
- hierarchy
- navigation
- tables
- forms
- controls
- action placement
- density
- touch targets

Prevent clipping, overflow, poor line lengths, and giant empty areas.

Verify representative viewports when browser tooling exists.
