# Code Review

Review actual diff and resulting behavior.

Focus on:
- correctness
- edge cases
- architecture
- security
- reliability
- performance
- realistic regression coverage

Do not rewrite for style.
Do not invent findings.

Use an independent reviewer subagent only when context isolation adds value.
