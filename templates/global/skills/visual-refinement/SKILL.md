# Visual Refinement

1. Run app.
2. Render representative desktop.
3. Inspect actual output.
4. Fix meaningful issues.
5. Render again.
6. Verify mobile/tablet.
7. Check interaction states.

Inspect:
- hierarchy
- spacing
- typography
- alignment
- overflow
- contrast
- density
- responsiveness

Use visual-reviewer when available.
Stop when remaining differences are subjective/low-value.
